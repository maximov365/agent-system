# Brand

This project-owned design passport records actual decisions. Populate the relevant
parts during substantial design work; an empty section is unknown, not permission
to replace an existing identity. Prefer links to existing design-system documents
and source tokens over duplicating their values. Framework sync preserves this file.

## Product and audience

- Primary users and tasks; platform, devices, input and supported languages.
- Product character and voice, with concrete examples of suitable copy.
- Existing brand constraints and which surfaces may explore a new direction.

## Visual direction

- Viewed references and what each contributes: composition, type, imagery, motion.
- Chosen direction and rationale; alternatives considered when useful.
- Density and hierarchy by surface: landing, application, reading, game interface.
- Deliberate distinguishing details and contextual avoid-list.

## System and implementation

- Canonical token/component paths and representative implemented screen.
- Type roles, font families/weights, language coverage and fallback behavior.
- Spacing/density, alignment, surfaces, radius, shadows and icon treatment.
- Semantic color roles, themes, focus/error states and measured contrast evidence.
- Image/asset manifest, display sizes/crops and source-to-export rules.
- Motion purpose, shared timing tokens, interruption and reduced-motion behavior.

## Acceptance and evidence

- Important routes/states, target viewports/devices and primary interaction.
- Reference captures with revision/date; performance/accessibility targets.
- Viewed results, material unresolved decisions and reasons for later changes.

Use `docs/DESIGN_CRAFT.md` for concrete techniques and `docs/VISUAL_QUALITY.md`
for acceptance. This passport belongs to the application, not the framework.
