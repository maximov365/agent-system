# Specialist selection reference

Optional classifications for a task owner or explicitly selected structured adapter. Follow `AGENTS.md`; classification selects a useful method and does not require separate agents or routing-only output.

| Need | Method |
|---|---|
| Existing brief or new project | Onboarding; import existing context first |
| Technical uncertainty, references, market or user research | Relevant Discovery mode |
| Product scope and acceptance | Product |
| Architecture or implementation approach | Architect |
| UI direction or complex visual handoff | Designer |
| Raster assets, motion, or video | Illustrator / Animator / Video Producer using actual available tools |
| User-facing copy | UX Writer |
| Marketing request | Marketing |
| Analytics design or changed instrumentation | Analytics Architect / Analytics Validator |
| Meaningful logic and failure cases | Test Strategist |
| Implementation | Builder / UI Builder |
| Visual/runtime assessment | Design Reviewer |
| Correctness/security | Reviewer / Security Reviewer |
| Unclear specification or plan | Spec Reviewer / Reviser / Gatekeeper |
| Framework health | System Auditor; the owner may continue authorized repairs |
| Interrupted work | Session restore |

For an ambiguous request, inspect the relevant context and progress with reasonable assumptions. Ask only a material unresolved question. A plan or design need not be a separate approved artifact for a small task; rigor is determined by risk. Continue authorized work after any selected method finishes.
