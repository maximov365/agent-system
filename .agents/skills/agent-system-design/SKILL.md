---
name: agent-system-design
description: Establish and implement visual direction for a new or substantially redesigned screen in an agent-system project. Use when composition or design identity must be decided.
---

Inspect the target's purpose, running incumbent, actual content and existing
brand/tokens. Use the existing design document; [the brand passport](../../../docs/BRAND.md)
is a seed, not a competing system. Identify whether this surface primarily supports
deciding, operating, reading, exploring or playing.

Use only the relevant [craft method](../../../docs/DESIGN_CRAFT.md): direction,
composition, typography, color/imagery or motion. Where direction is open, compare
a few different compositions of one representative screen, choose with reasons,
and bring that screen to the intended finish before expanding the pattern.

Implement real components and appropriate assets. Preserve factual copy, identity,
platform conventions and scope. Existing tokens win over arbitrary style bans.
Follow [visual acceptance](../../../docs/VISUAL_QUALITY.md), exercise the primary
journey and view the running result at its target sizes. Persist consequential
design decisions with links to source tokens and reviewed evidence.
